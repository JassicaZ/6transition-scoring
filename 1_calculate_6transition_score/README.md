# 6-Transition Score Calculation

## Overview

This repository contains a Docker-based pipeline that processes single-cell RNA-seq data to produce individual 6-transition scores.

The workflow consists of:

1. CellTypist annotation and pseudobulk aggregation
2. Preprocessing and normalization of pseudobulk data
3. Calculation of sample-level 6-transition scores

## Quick Start

### 1. Pull the Docker image

```bash
docker pull zjyplus/6transition_scoring_env:2.0
```


### 2. Run the pipeline

```bash
docker run --rm \
    -v <your_input_folder>:/data \
    -v <your_output_folder>:/results \
    zjyplus/6transition_scoring_env:2.0 \
    ./run.sh --run-all \
    --qc-h5ad <your_input_folder>/<your_QC_h5ad>.h5ad \
    --neighbors-h5ad <your_input_folder>/<your_neighbors-h5ad>.h5ad \
    --clinical-csv <your_input_folder>/<your_cli_csv>.csv \
    --output-path /results
```
####  Example: Run the pipeline using built-in example data:
```bash
unzip ./data/example/JIA_preprocessed.zip -d ./data/example
unzip ./data/example/JIA_QC.zip -d ./data/example

docker run --rm \
    -v ./data:/data \
    -v ./results:/results \
    zjyplus/6transition_scoring_env:2.0 \
    ./run.sh --run-all \
    --qc-h5ad /data/example/JIA_QC.h5ad \
    --neighbors-h5ad /data/example/JIA_preprocessed.h5ad \
    --clinical-csv ./data/example/JIA_cli.csv \
    --output-path /results
```
## Input files

### `--qc-h5ad`

QC-filtered single-cell `.h5ad` file with raw counts.

### `--neighbors-h5ad`

Processed `.h5ad` file containing the neighbor graph (for example after Harmony integration and neighbor construction).

Required contents:

- `uns["neighbors"]`
- `obsp["connectivities"]`
- `obsp["distances"]`

### `--clinical-csv`

Clinical information table,formated as a headered CSV with sample IDs as row names

Required columns:

- sample ID
- age
- sex
- batch column (optional, specified by `--batch-col`)


## Output

The pipeline writes results under `--output-path`:

- `ct_pseudobulk/`: pseudobulk expression CSV files generated by CellTypist
- `preprocess/preprocessed_matrix.csv`: normalized and preprocessed matrix for scoring
- `transition_score/transition_scores.csv`: final per-sample transition scores

## Built-in example data

This repository includes test data under `data/example/`.
The example dataset is from _Imbach KJ et al. Pediatr Rheumatol Online J. 2023_ (PMID: 36793127) and contains data from six juvenile idiopathic arthritis (JIA) patients.
